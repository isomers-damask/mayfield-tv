# Putting MAC TV on the lobby PC

1. Copy `Setup-Lobby-PC.ps1` to the mini PC (USB stick, email, or download it from GitHub).
2. Right-click it, choose **Run with PowerShell**. If Windows blocks it, open PowerShell and run:
   `powershell -ExecutionPolicy Bypass -File .\Setup-Lobby-PC.ps1`
3. Do the automatic sign-in step it prints, so the TV comes back on its own after a power outage.
4. Close the old ChiroTV program and take its shortcut out of Startup, so the two don't fight over the screen.

Keyboard on the TV: arrow keys skip slides, M toggles music, F full screen, Alt+F4 closes it. Moving the mouse shows the control bar.
